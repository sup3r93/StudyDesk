# AI development disclosure

StudyDesk is being developed primarily with artificial intelligence, specifically **OpenAI Codex**,
under the repository owner's direction. AI is used to write and revise code, documentation,
configuration and tests.

This statement describes the development process. It does not imply that all code has received
independent human review, that generated tests prove correctness, or that a release is safe merely
because automated checks pass.

Contributions must disclose material AI assistance in their pull request. Authors and maintainers
remain responsible for understanding changes, preserving third-party notices and reporting the
validation actually performed.

No AI feature is currently planned inside the application. Development assistance does not authorize
sending users' notes, attachments, tokens or personal data to an external AI service.

Releases must describe known limitations and distinguish implemented functionality from planned
behavior. Security, synchronization, deletion, recovery and clinical calculations require explicit
review and meaningful behavioral tests before release.
